# 拓展语种调研记录（唯一一份）

> ⚠️ **实验版（experimental）**：本仓除**中粤**（普通话 `mandarin`、粤语 `cantonese`）以外的一切语种
> 都是**实验**，**不得当作出厂词库**，也不代表本仓支持该语种。完整研究过程（5 份文档，约 363 KB）
> 已于 2026-10-02 删除，**只留本记录**；需要原文时见本文末的取回锚点。

## 1. 边界（三条硬约束）

1. **出厂默认只有中粤** —— `mandarin` / `cantonese`。
2. 新增语种**一律标「实验版」**，其语料、清单、统计、词典**只在本仓**出现；**cpp-pinyin 仓不得出现**
   这些语种的记录（该仓只留方法与决策）。
3. 本记录是**调研结论**，不是规范，也不构成任何达标声明。

## 2. 语种结论一览

| 语种 | 状态 | 结论与理由 |
|---|---|---|
| 闽南语 | 走通全链路 | 可作为**新语种模板**；指标口径与格式约束的实例都出自它 |
| **潮州话** | 曾达 L1（实验版），**现出仓** | 曾照 `gen/cantonese.py` 模板走**与中粤完全相同的 `MakeDict` 流水线**（无手搓表、无方言专属引擎分支）；成绩记录见原文档（**87.38% 与 86.87% 出自不同轮次、口径不同 ⇒ 引用前必须复核**）。**2026-10-02 按用户裁定：只留记录，代码（`teochew.py`）与数据（`data/tc_*.txt`／`tc_overrides.py`）出仓** |
| 客家语 | 🔒 **结案** | 结论**不是分数低**，而是**记录值不可复现**（重建计分器复现未遂，差 8~18pt，成因逐条定位）⇒ 依项目纪律「不可复现的数字不得当达标依据」⇒ **本语种不存在可信达标数字**，不再投入。重启前提＝**先重建金标与尺子**。另一独立结论：固定分母下「只靠调整读音顺序」的上限 **88.38% < 90%** |
| 吴语（上海话） | ❌ 结构性障碍 | **缺整句金标** —— 不是缺数据、也不是"还没优化"；盘上无语级金标，网搜亦无 |
| 越南语 | 达标可评 | 与客家/潮州并列的三处可评语种之一 |
| 其他（赣语等） | 优先级低 | 多音率低（如某候选仅 5.7%）⇒ 分母小，能测出的东西有限 |

## 4. 判据（新增语种必须遵守；这几条都是真踩过的）

1. **尺子必须与受测语料无关**，否则就是把答案抄进尺子；**重排必须由独立权威给出**。
2. **多音要在"去调后"判**（`do, dó` 只差调号不算多音），否则分母虚胀。
3. **无声调化必须按语种实现**：禁止「NFD 分解后删掉所有组合字符」——`ê` 与 `e` 是两个不同韵母
   （/ɛ/ 与 /e/），折叠会把不同音节并成一个（实测：某语种上折叠使成绩从 **86.91% 掉到 60.17%**，
   −26.74pt）⇒ 相关历史数字一律作废。
4. **记录值不可复现 ⇒ 不得当达标依据**（客家语的教训）；重建的尺子也要**先过退化自检**。
5. **门槛逐语种单独定**；达标必须同时满足"同一条流水线产出、无手搓表、无方言专属引擎分支"。
6. **引号类反模式**：同一进程内多语种词典并存时必须互不干扰；「自建滑窗模型推断引擎路径」得到的
   分桶**不是**引擎实际路径，不得当成绩。
7. **跨仓先查**：引用任何语种结论前，**先查另一仓**的结论是否已推翻它（本项目已三次踩到：
   吴语、越南语、客家语各一次）。
